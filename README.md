# AgendaFácil
O AgendaFácil é um sistema de agendamentos de atendimentos de uma clínica pequena.

## Funcionalidades
* **Adicionar atendimento**: Marca um novo atendimento de um cliente na agenda para uma determinada data e hora com um profissional da clínica
* **Remaracar atendimento**: Permite remarcar o horário e a data de um atendimento já registrado na agenda
* **Listar agendados**: Lista os atendimentos existentes em uma data específica

## Tecnologias
* Python 3 
* Pdoc

## Como compilar e executar
Na pasta raiz do projeto execute:

`py src/agenda_base.py`

## Documentação 
Para gerara a documentação da API, na pasta raiz do projeto execute:

`pdoc src/agenda_base.py -o docs/`
